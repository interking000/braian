CATEGORÍAS

Información de categorías
¿Para qué sirve?

Acá podés organizar tus servidores por categorías (por ejemplo: Gratis, VIP, VIP 3, etc.).
Cada categoría define el nombre, el color y el estado (ACTIVO / INACTIVO).

Tip: mantené las categorías claras para que el cliente elija rápido y no se pierda.
